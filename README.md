# 🎮 Tic Tac Toe AI

Красивый браузерный вариант классических крестиков-ноликов с искусственным интеллектом.

### Возможности
- 🤖 3 уровня сложности: легко, средне, эксперт
- 🧠 Minimax AI на максимальной сложности
- ✨ Анимации ходов и победы
- 🎉 Эффект конфетти при победе
- 🏆 Счётчик результатов
- 📱 Адаптация под смартфоны
- 🌌 Современный glassmorphism-интерфейс
- ⚡ Никаких зависимостей
- 📴 Работает без Python и сервера

## Запуск

Откройте `index.html` в браузере.

## GitHub Pages

1. Создайте публичный репозиторий.
2. Загрузите `index.html` и `README.md`.
3. GitHub → **Settings → Pages**.
4. Source: **Deploy from a branch**.
5. Branch: **main**, Folder: **/ (root)**.
6. Сохраните.

После публикации GitHub даст публичную ссылку, которой можно поделиться с кем угодно.

## Технологии

HTML5 · CSS3 · JavaScript · Minimax
